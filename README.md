# MusicVis Live — живые обои с аудиовизуализацией

Android-приложение с живыми обоями, которые рисуют музыку в реальном времени: спектр, волны, осциллограф, светомузыка и другие режимы. Работает от системного звука (Visualizer API) или от микрофона.

*Live wallpaper audio visualizer for Android: real-time spectrum, waveform, oscilloscope, light-show and more. English and Russian UI included.*

## Предыстория

На старых Android были классические живые обои «Фоновые рисунки: аудиовизуализация» (MusicVis из AOSP, `com.android.musicvis`) — лёд, огонь, VU-метр, столбики под музыку. На современном смартфоне (vivo, OriginOS, Android 16) они больше не работают: это был **системный** пакет, который нельзя просто установить поверх прошивки, а `Visualizer` без runtime-разрешения `RECORD_AUDIO` и активной сессии воспроизведения молчит. Моды старого APK — костыль, живущий только на старых прошивках.

Поэтому визуализатор написан заново с нуля: та же идея «обои, которые рисуют музыку», но на современных API (WallpaperService + Visualizer/AudioRecord, OpenGL ES 2.0, 120 Гц), с новыми режимами и настройками. Оригинальное приложение осталось источником вдохновения — от него унаследованы, например, VU-метр и палитры «лёд/огонь».

## Режимы

**Реагируют на громкость телефона** (системный звук):
- Спектр (FFT, OpenGL) — частотные столбики
- Октавный спектр (OpenGL) — логарифмическая шкала частот
- Волна столбиками (OpenGL) — форма волны
- Водопад — скроллящаяся спектрограмма
- Светомузыка — экран как цветомузыкальная установка (бас/середина/верх)

**Не зависят от громкости**:
- VU-метр — аналоговая стрелка
- Точки — история волны частицами
- Осциллограф — сырая форма сигнала
- Радиальный спектр — частоты по кругу

## Возможности

- OpenGL ES 2.0 рендеринг основных режимов (плавно на 120 Гц)
- Источник звука: системный вывод или микрофон (свой FFT для AudioRecord)
- Настраиваемые цветовые палитры и градиенты (HSV-редактор, пресеты)
- Фон: чёрный или «дышащий» градиент из палитры
- Эффекты вечеринки: вспышки в такт, автосмена цвета, ударные волны, неоновые трейлы, мастер-режим Party
- Вибрация в такт музыке (пресеты: бочка/бас/RMS, чувствительность, сила, мин. интервал)
- Экран «Проба спектра» для живой настройки FFT и вибрации
- Локализация: русский и английский, выбор языка внутри приложения

## Сборка

Требуется Android SDK (compileSdk 36), JDK 17+. Минимальная версия Android — 8.0 (API 26).

```bash
./gradlew assembleDebug
adb install app/build/outputs/apk/debug/app-debug.apk
```

Для захвата системного звука приложению нужно разрешение `RECORD_AUDIO` и активное воспроизведение музыки; для режима микрофона — только `RECORD_AUDIO`.
